# Morning Desk — laptop kiosk

Turn a spare Mac into the morning/evening display: it wakes itself, opens the
dashboard fullscreen (no PIN), and lets you tap the outfit to adjust — no tablet.

Runs twice a day by default: **06:30** and **22:00** (10pm, to plan the next day).

## Files
- `setup.sh` — one-time install: mints a no-PIN token, schedules both wakes
  (`pmset`), installs a launch agent (`launchd`) that opens the kiosk a minute
  after each wake. Self-rearms so it fires even from deep sleep.
- `morning-kiosk.sh` — the launcher (auto-generated by setup; token baked in,
  gitignored). Opens Chrome in `--kiosk` on the dashboard.
- `rehearse.sh` — schedule a wake ~2 min out so you can `pmset sleepnow` and watch
  the real wake-from-sleep behaviour now.
- `uninstall.sh` — remove the schedule.

## Install (on the kiosk laptop)
```bash
cd ~/Projects/morning-desk && git pull
bash kiosk/setup.sh        # enter your dashboard PIN once + your Mac password once
```
Needs **Google Chrome** installed.

## Test it
- **Display only (no sleep):** `bash kiosk/morning-kiosk.sh`  (Cmd+Q to quit)
- **Full wake-from-sleep rehearsal:** `bash kiosk/rehearse.sh`, then `pmset sleepnow`,
  and watch it wake ~2 min later and open the kiosk.

## Change times / undo
- Edit `MORNING` / `EVENING` at the top of `setup.sh`, delete `morning-kiosk.sh`,
  and re-run `bash kiosk/setup.sh`.
- Remove everything: `bash kiosk/uninstall.sh`.

## Notes
- Uses the laptop's own screen — no external monitor / flaky cable.
- `setup.sh` adds a scoped `sudoers` rule (`/usr/bin/pmset` only) so the schedule
  can re-arm itself without a password. `uninstall.sh` removes it.
- The token in `morning-kiosk.sh` is a bearer credential for this device — keep it
  private (it's gitignored). Evangeline's closet is one tap away (her PIN once).
